Token Launch Radar: every protocol DefiLlama tracks that records no token, ranked by an implied value priced from the market's own live-token comparables (model radar-2), with a 6-step farm plan per protocol. 198 rows: all 40 watchlist protocols plus 158 early finds outside the watchlist.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```

Then open `out/dashboard/index.html`. No network is used at runtime; all data is embedded in `out/data.js`.
