Methodology — how the number is made

Implied value = TVL × category multiple × growth multiplier × maturity multiplier.

  • Category multiple: median market-cap / TVL of the snapshot’s own live-token protocols in the same category, shrunk toward the global median 0.214 with prior weight 3. Categories with fewer than 3 live comparables use the global median — a single comparable at 2.98× (Risk Curators) or 400× (Prediction Market) never sets a price.
  • Growth: 7-day TVL change clamped to −50%…+100%, weight 0.6. Maturity: 0.65 + min(age, 1095 days) / 1095 × 0.35; unknown listing date counts as 365 days.
  • Scope: 758 protocols in the sealed snapshot (DefiLlama, 2026-11-14, floor $5M). The board ranks all 40 watchlist protocols (TVL ≥ $50M, no token recorded, not a wrapped/staked/bridged product) plus the 160 largest clean pre-token protocols outside the watchlist — the early radar, including clean protocols above the floor the watchlist leaves out. Live-token protocols are shown apart, never ranked.
  • Honesty: “records no token” means DefiLlama records none — it is not proof a token does not exist. Implied value is this radar’s own claim from the snapshot’s figures; it does not predict whether or when a token launches.
